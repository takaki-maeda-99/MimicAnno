## 推奨手順

1. **ユーザー sign-off**: 下の質問でカテゴリごとに OK/NG をもらう
2. Tier 1 の `_vlm_dumps/*.jsonl` を `find runs/ -name '*.jsonl' -newer ...` で詳細リスト化し、現行 v5 dir に同等品があるか確認 (重複なら削除、無ければ `_vlm_dumps_archive/2026-05-15/` へ退避)
3. `git ls-files --others --ignored --exclude-standard runs/ data/` で全部が `.gitignore` 済みであることを確認
4. Tier 1 → Tier 2 → Tier 3 の順に `rm -rf`
5. 完了後: `du -sh runs data/depth data/video data/hands` で削減量を記録

## 想定削減量

- Tier 1 のみ: **~7.7G**
- Tier 1 + Tier 2: **~7.7G** (Tier 2 は誤差)
- Tier 1 + Tier 2 + `data/video/` 古 MP4: **~24G** (16G + 7.7G)
