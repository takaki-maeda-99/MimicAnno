## Summary

Implements U-A2 of the U-A initiative — dataset-level annotation summary backend + dashboard tab on `/datasets/{name}`. Per master spec rev3 §3.2 + §2.2 (`docs/superpowers/specs/2026-05-17-ua-dataset-processing-ui-design.md`).

- **Backend**: `GET /api/datasets/{name}/summary?run_set=<rs>` aggregates `annotation.json` per ep across the chosen run_set → label distribution, segment count stats (mean / min / max), reviewed rate, per-ep summary. Defaults to most-recent run_set when `run_set` omitted.
- **Frontend**: Summary tab inside `DatasetsPage` with bar chart of label distribution (descending by count, alphabetical tiebreak), per-ep stats table, run_set context display.
- `label_diversity` defined as **number of distinct `phase` values per episode** — `phase` is the primary label, always present (unlike `verb`/`object` which can be null on degraded paths). Documented in sub-spec.

Touches master §2 contract: no
